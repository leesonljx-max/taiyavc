# V2.1.0 实施计划：团队评价体系 + 投后管理模块

## Context

用户两个新需求：
1. **任务一（团队评价）**：将附表《创业团队评价模型V1.xlsx》系统化到项目尽调"团队与治理"模块——AI 从已上传简历识别成员身份（实控人CEO/联创CTO/CMO/核心高管），生成打分表格（一级权重固定：实控人独占60、团队整体独占20、其余成员共享20取平均；二级权重可调但每人合计100%；评分0-10；最终10分制，>8绿/7.5-8黄/7-7.5橙/<7红）
2. **任务二（投后管理）**：一级栏目"投后管理"（项目尽调下方），按《投后管理功能开发.docx》文档 MVP 范围：每季上传经营报告/财务报表/BP → 文档解析 → 指标提取入库 → 程序计算同比环比 → AI 分析（财务/异常/现金流/业务/风险）→ 指标Dashboard + 分析报告 + 证据溯源

用户已确认的决策：
- 投后管理仅显示 `followStage=POST_INVESTMENT`（投后）的项目
- 团队评价简历从"团队与治理"模块资料中心已上传文档识别
- 团队评价未确认 → 团队与治理模块视为不完整 → 阻塞"生成尽调报告"

## 一、任务一：团队评价体系

### 1.1 Schema（prisma/schema.prisma）

```prisma
model DDTeamEvaluation {
  id          String    @id @default(cuid())
  projectId   String    @unique
  membersJson String    // 成员打分表 JSON
  teamJson    String    // 团队整体打分 JSON
  status      String    @default("DRAFT") // DRAFT / CONFIRMED
  finalScore  Float?
  confirmedAt DateTime?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  project     Project   @relation(fields: [projectId], references: [id], onDelete: Cascade)
}
```
Project 加反向关系 `teamEvaluation DDTeamEvaluation?`。执行 `npx prisma db push`。

### 1.2 lib：src/lib/dd-workbench/team-evaluation.ts（新建）

**评价模板**（从 xlsx 提取，含 label/hint/默认权重/分组）：
- `CEO_TEMPLATE`（13 维度，系数60）：创业素质[学历背景0.05/从业经验0.15/商业思维0.15/融资能力0.10/制度建设0.10/战略能力0.05/号召力0.05/人品性格0.05/格局愿景0.05] + 创业意愿[投入资金0.05/投入精力0.05/家境支持0.05/薪酬0.10]
- `TECH_TEMPLATE` 产品&技术画像（10 维度，系数20）：学历背景0.10/从业经验0.15/参与角色0.15/能力互补性0.10/人品性格0.05/投入资金0.10/投入精力0.05/薪酬0.15/持股情况0.10/家境支持0.05
- `OPS_TEMPLATE` 运营&销售画像（10 维度，系数20）：学历背景0.10/从业经验0.15/参与角色0.15/商业嗅觉0.05/能力互补性0.05/人品性格0.05/投入资金0.05/投入精力0.10/薪酬0.15/持股情况0.10/家境支持0.05
- `TEAM_TEMPLATE` 团队整体（4 维度，系数20）：完整性0.25/可扩展性0.10/过往连接0.40/利益绑定0.25

**类型与计算**：
- `TeamMember { id, name, roleLabel, profileType: 'CEO'|'TECH'|'OPS', dimensions: [{key, label, hint, group, weight, score: number|null}] }`
- `computeEvaluation(members, team)`：CEO得分=Σ(weight×score×6)；各高管得分=Σ(weight×score×2)；高管平均（无高管时0）；团队得分=Σ(weight×score×2)；finalScore=(三项和)/10（与 Excel 公式一致：H=F×G×6/2）
- 颜色函数：>8 绿 / 7.5-8 黄 / 7-7.5 橙 / ≤7 红

**AI 成员识别** `runMemberExtraction(projectId)`：
- 读 `getProjectModuleResources` 的 TEAM_GOVERNANCE 模块资料（文档全文+文本框）
- DeepSeek（deepseek-v4-flash、90s 超时、`parseAgentJson`）提取 `[{name, roleLabel, profileType}]`，身份映射规则写入 prompt（实控人/CEO/创始人→CEO 唯一；CTO/技术/产品/研发→TECH；CMO/销售/市场/运营/财务/法务/其他→OPS）
- 无资料返回 `{ok:false}`；无实控人时提示

### 1.3 API（4 个路由，权限同 DD 资源：canEditResearchProject / canViewResearchProject）

| 路由 | 功能 |
|---|---|
| `GET /api/dd/team-evaluation/[projectId]` | 获取评价表（无则 `{evaluation: null}`） |
| `POST .../team-evaluation/[projectId]/generate` | AI 识别成员生成打分表；已 CONFIRMED 409；模块无资料 400 |
| `PUT .../team-evaluation/[projectId]` | 保存权重+评分；校验每人权重合计=100%（±0.5%容差）、评分0-10 |
| `POST .../team-evaluation/[projectId]/confirm` | 校验全部已评分 → 计算 finalScore → CONFIRMED；CONFIRMED 状态再调可重开为 DRAFT |

### 1.4 报告门槛（src/lib/dd-workbench/resources.ts）

`isModuleComplete` 对 TEAM_GOVERNANCE 特殊化：资料完整 **且**（无评价表 或 status=CONFIRMED）。`findMissingModules` 文案对团队与治理追加"（需确认团队评价表）"。

### 1.5 前端（src/components/dd-workbench/DDWorkbenchShell.tsx）

新增 `TeamEvaluationCard` 组件，挂在 TEAM_GOVERNANCE 模块详情区左列（人工结论下方）：
- **未生成**："📋 生成团队评价表"按钮 + 提示（需先在资料中心上传简历）
- **DRAFT 可编辑**：三区段表格

  - 20分区（联创&核心高管）：成员 tab 切换（各自画像模板），显示"平均分"汇总
  - 20分区（团队整体）
  - 权重合计≠100% 红字提示；底部"保存草稿"+"✅ 确认评分"（全部评分后可用）

- 九宫格团队与治理卡片：评价未确认时加"📋 待评价"角标

## 二、任务二：投后管理（MVP，按文档三十七章裁剪）

### 2.1 Schema

```prisma
model PostInvestDoc {
  id String @id @default(cuid())
  projectId String
  docType String    // OPERATION_REPORT / FINANCIAL_STATEMENT / BP / OTHER
  period String     // 2026Q1 / 2026H1 / 2026FY
  fileName String; fileUrl String; fileType String; fileSize Int
  text String       // 提取全文
  uploadedById String
  createdAt DateTime @default(now())
  project Project @relation(..., onDelete: Cascade)
  @@index([projectId])
}
model PostInvestMetric {
  id String @id @default(cuid())
  projectId String; period String; periodType String  // Q / H / FY
  metricKey String; metricName String; category String  // financial / business
  value Float; unit String
  sourceDocId String?; sourceText String?  // 证据溯源
  createdAt DateTime @default(now())
  @@unique([projectId, period, metricKey])
}
model PostInvestAnalysis {
  id String @id @default(cuid())
  projectId String; period String
  summaryJson String  // AI 结构化分析
  createdAt DateTime @default(now())
  @@unique([projectId, period])
}
```

### 2.2 lib：src/lib/post-investment/（新建目录）

- **metrics.ts**：指标字典 15 项（营业收入/毛利润/毛利率/净利润/净利率/经营现金流/现金余额/总资产/总负债/净资产/应收账款/存货/新签订单/在手订单/交付订单+融资额），含 key/name/unit/category
- **extract.ts**：`POST_INVEST_EXTRACT_SYSTEM_PROMPT`——输入文档全文+指标字典，输出 `[{metricKey, value, unit, sourceText}]`（严格匹配字典、附原文证据）
- **calc.ts**：程序化同比/环比引擎（LLM 不算数）：
  - 环比：仅 Q→Q（Q1 的上期为上年Q4）；H 不与 Q 互算；FY 无环比
  - 同比：Q vs 上年同 Q、H vs 上年同 H、FY vs 上年 FY
  - 分母 0 / 上期为负 / 缺失 → null（前端显示 "-"）
- **analysis.ts**：`runPostInvestAnalysis(projectId, period)`：
  1. 汇总该期全部文档全文 → DeepSeek 提取指标 → upsert PostInvestMetric
  2. 读历史各期指标 → calc.ts 计算同比/环比
  3. DeepSeek 分析（输入=指标+同比环比+文档要点摘要，输出结构化 JSON）：`{ executive_summary, financial_analysis[], anomalies[{level: high/medium/positive, title, detail, evidence}], cashflow_analysis{cash_balance, runway_months, assessment}, business_progress[{area, rating(1-5), detail}], risk_alerts[{type, level, description, evidence}] }`
  4. 幻觉控制写入 prompt：所有数字必须来自输入结构化数据、每条结论带证据
  5. 存 PostInvestAnalysis

### 2.3 API

| 路由 | 功能 |
|---|---|
| `GET /api/post-investment` | 投后项目列表（followStage=POST_INVESTMENT + canViewResearchProject 过滤）+ 各项目最新期分析摘要/风险统计 |
| `POST /api/post-investment/documents` | 上传（projectId/period/docType/file）→ `extractTextFromFile`（复用 src/lib/document-extract.ts）→ 存库；文件存 `public/post-investment-docs`（复用 research-docs 模式） |
| `DELETE /api/post-investment/documents?docId=` | 删除记录+本地文件 |
| `POST /api/post-investment/[projectId]/analyze` | body{period} → runPostInvestAnalysis |
| `GET /api/post-investment/[projectId]` | 详情：文档按期分组 + 各期指标 + 同比环比矩阵 + 最新分析 |

### 2.4 前端

- **DashboardLayout.tsx**：navItems 在项目尽调后插入 `{href:'/post-investment', label:'投后管理', icon}`（新 SVG 图标）
- **/post-investment/page.tsx**（列表，复用 research 列表模式）：概览卡（投后项目数/本季已提交/待提交/风险项目数）+ 项目卡（项目名+行业+最新期核心结论摘要+风险等级徽章）
- **/post-investment/[projectId]/page.tsx**（详情）：
  - 上传区：报告期选择（近8个季度/H1/FY 下拉）+ 文档类型（经营报告/财务报表/BP/其他）+ 多文件上传（accept .pdf,.docx,.xlsx,.txt,.md）
  - 报告期选择器（已有期次 tab）+ "🔍 AI 分析本期"按钮
  - 指标 Dashboard：本期指标表（指标/本期值/同比/环比/状态），历史趋势行（各期值）
  - AI 分析卡：核心结论、异常指标（🔴/🟠/🟢 分区）、现金流健康（现金余额+runway 月数+评估）、业务进展（⭐评级）、风险提示（类型+级别+证据）
  - 文档列表（按期分组，DocumentPreviewModal 预览）
